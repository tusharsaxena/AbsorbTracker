# 02 — Deviations

**Audited against:** Ka0s WoW Addon Standard **v2.21.0 (2026-08-04)**. All 25 section files listed
by `STANDARDS.md` were fetched by following the index's Sections links and read; none is unassessed.
See `01_CURRENT_STATE.md` for provenance and `03_EVIDENCE.md` for every citation.

**Verdict: minor deviations.** The structural surface is right and has stayed right: five LibKa0s
seams with complete degradation stubs, whole-folder vendoring with the aggregate `.xml` TOC-listed
once, the retired `docs/complexity.md` gone, the three-place standards reference intact, the root
doc set and the `docs/` canonical trio and all five required topic-detail docs present, both gate
commands green and zero functions over CCN 15. What remains is concentrated in **records and prose**
— a doc set that has not caught up with the v2.21.0 release gate, a runner that cannot execute from
a fresh clone, and two measurement artifacts that say something the code does not do.

**Counts:** MUST **7** · SHOULD **6** · MAY **4**.

**IDs.** Prefix `AT-`, continuing from `docs/audits/2026-08-04/` (highest prior `AT-41`). `AT-30`,
`AT-31`, `AT-33` … `AT-41` recur and keep their IDs. **`AT-32` is resolved** — see the closure list.
New this run: `AT-42` … `AT-50`.
